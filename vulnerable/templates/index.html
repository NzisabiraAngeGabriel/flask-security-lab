Welcome to the SecLab Training Portal

This portal is the front-end for the Flask Security Lab — an intentionally vulnerable web application built for local, controlled security training. It ships in two builds running side by side:

Vulnerable build

http://127.0.0.1:5000

Contains four deliberately unsafe endpoints for demonstration.

Secure build

http://127.0.0.1:5001

Same functionality, hardened against the same four attacks.

What you can practise here

  • SQL injection on the resource search endpoint.
  • Stored XSS on the comments feed.
  • OS command injection on the network diagnostic tool.
  • Directory traversal on the resource viewer.

Getting started

  1. Register a new account, or log in as alice / password123 or bob / hunter2.
  2. Explore the tools in the sidebar. Each is safe to use as intended.
  3. For the security demonstrations, see the lab write-up.

This application is bound to 127.0.0.1 and must never be exposed to a network. All test payloads stay on this machine.
